# Temp Landing Page

A simple landing page project created as part of my personal learning journey in **Web Development, Git, and GitHub**.

## 📌 About the Project

This repository contains a temporary landing page developed for practice and experimentation. The primary objective is to understand how Git and GitHub work together in a real-world development workflow.

Rather than focusing only on writing code, this project helps me learn how to manage files, track changes, maintain version history, and collaborate with remote repositories.

## 🎯 Learning Objectives

Through this project, I aim to understand:

- How to initialize a Git repository.
- How to track changes using Git.
- How to stage and commit files.
- How to write meaningful commit messages.
- How to create and manage branches.
- How to connect a local repository to GitHub.
- How to push local changes to a remote repository.
- How to pull updates from GitHub.
- How to understand the relationship between Git and GitHub.
- How to manage a project using basic version control practices.

## 🛠️ Technologies Used

- **HTML5** – For structuring the landing page.
- **CSS3** – For styling and layout.
- **JavaScript** – For basic interactivity.
- **Git** – For version control and tracking project changes.
- **GitHub** – For remote repository hosting and project management.

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash

   ```

2. Navigate to the project directory:

   ```bash
   cd temp-landing-page
   ```

3. Open `index.html` in your browser.

## 📚 Git Commands Practiced

Some of the Git commands I am learning and practicing through this repository:

| Command | Purpose |
|---|---|
| `git init` | Initialize a new Git repository. |
| `git status` | Check the current repository status. |
| `git add .` | Stage changes for the next commit. |
| `git commit -m "message"` | Save changes in the repository history. |
| `git log` | View previous commits. |
| `git branch` | List available branches. |
| `git checkout` | Switch between branches. |
| `git push` | Upload local commits to GitHub. |
| `git pull` | Fetch and integrate remote changes. |
| `git clone` | Copy a remote repository locally. |
